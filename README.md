# assets

Recursos centralizados (estilos, fuentes, logos e isotipos) para las aplicaciones de la Universidad Distrital.

## Contenido

- `*.css`: hojas de estilo compartidas
- `OpenSans-*.ttf`, `*.woff2`: fuentes
- `isotipos_aplicativos_svg/`, `logotipos_aplicativos_svg/`, `*.png`: isotipos y logotipos
- `apps.json`: listado de aplicaciones
